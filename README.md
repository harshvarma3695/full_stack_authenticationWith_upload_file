# 🔐 Full Stack Authentication System with File Upload

A complete Full Stack Authentication System built using **Node.js, Express.js, MongoDB Atlas, EJS, Multer, and Cloudinary**. This project provides secure user authentication along with profile image upload functionality.

---

## 🚀 Features

* ✅ User Registration
* ✅ User Login & Logout
* ✅ Password Authentication
* ✅ Profile Image Upload
* ✅ Cloudinary Image Storage
* ✅ MongoDB Atlas Database
* ✅ Express.js Backend
* ✅ EJS Template Engine
* ✅ Responsive UI with Bootstrap
* ✅ Secure File Upload using Multer

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap, EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Authentication:** Custom Authentication
* **Image Storage:** Cloudinary
* **File Upload:** Multer
* **Version Control:** Git & GitHub

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/harshvarma3695/full_stack_authenticationWith_upload_file.git
```

### Go to project folder

```bash
cd full_stack_authenticationWith_upload_file
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

Add your credentials:

```
MONGO_URI=your_mongodb_connection_string

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

### Run the project

```bash
node server.js
```
